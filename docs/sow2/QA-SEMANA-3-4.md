| Caso | Resultado a demostrar |
|---|---|
| Sin sesión, wallet cambiada, perfil inactivo o autorización médica vencida/revocada | Rechazo sin contenido clínico ni firma |

| Corrección de paciente u otro médico | Rechazo; sólo autor/última versión y revisión esperadas |
| Receta ajena o de otro paciente | Vínculo rechazado; permiso clínico no concede acceso al documento |
| Receta revocada/vencida o fallo del proveedor | Estado verificado explícito; nunca una confirmación falsa ni un documento anterior presentado como actual |
